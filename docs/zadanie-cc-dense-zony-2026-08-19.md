# Задание C C: плотный этап (PatchMatch) по 14 зонам

Модель участка вещей (PR #12) показала себя лучшим представлением рельефа
из всех, что были у проекта. Раскатываем тот же способ на остальные
отснятые зоны: сцену кошек, вещи 15.08, стену, гору и линию падения.

С нашей стороны готово всё до GPU-этапа: по каждой зоне выбрана
sparse-модель с максимумом камер и собрано рабочее пространство COLMAP
(андисторт до 1600 px, конфиги на месте, включая
`run-colmap-geometric.sh`): `analysis/scene3d/data/<зона>/dense/`,
суммарно 1.6 ГБ. Канал передачи файлов согласуется отдельно
(закрытый контур, публиковать нельзя).

## Что просим запустить (на зону — две команды)

```bash
docker run --rm --gpus all -v "$PWD/<зона>/dense:/w" colmap/colmap:latest \
  colmap patch_match_stereo --workspace_path /w --workspace_format COLMAP \
  --PatchMatchStereo.geom_consistency true --PatchMatchStereo.max_image_size 1600

docker run --rm --gpus all -v "$PWD/<зона>/dense:/w" colmap/colmap:latest \
  colmap stereo_fusion --workspace_path /w --workspace_format COLMAP \
  --input_type geometric --output_path /w/fused.ply
```

Вернуть достаточно `fused.ply` по каждой зоне (карты глубины не нужны).

## Зоны в порядке ценности

| зона | камер | ожидание GPU* |
|---|---|---|
| koshki-1608 — сцена кошек 16.08, три ролика | 134 | ~55 мин |
| veshchi-15 — вещи 15.08 | 47 | ~20 мин |
| stena-peak — стена под вершиной | 86 | ~35 мин |
| gora-obzor — обзор горы | 217 | ~90 мин |
| linia-01, 05–13 — линия падения сверху вниз | 33–212 | по числу камер |

*по замеру PR #12: 52 кадра = 21.5 мин на RTX 4070 Ti SUPER.

В сумме ~1500 камер ≈ 10 часов GPU; если целиком много — приоритет
первым четырём строкам.

## Что дальше на нашей стороне

Геопривязка облака по телеметрии (вне подгонки — лазерные точки),
поверхность и ортотекстура (`src/drape.py`), упаковка вставкой в наш
3D-плеер «Полёт» (`analysis/scene3d_insert.py`) — механика обкатана на
модели участка вещей 19.08.

Оговорка по зонам зависаний: если в зоне камеры стоят на месте
(база между полётами не сшилась), масштаб не определён —
`scene3d.telemetry_degeneracy` такие отбраковывает; их пропускаем без
сожаления, это честное «глубины тут нет».

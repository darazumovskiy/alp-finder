## 1. Снегомерная рейка + time-lapse камера

**Что измеряет:** высоту снега по градуированной рейке (и косвенно — интенсивность/время снегопада, ветровой перенос). Плюс визуальный контроль погоды.

**Точность:** при чтении человеком — 1–2 см; автоматически — RMSE «несколько см» (Filhol 2019 [20]), CNN Mask R-CNN — полностью автоматом [21]; FMIPROT (финско-итальянский кейс) [22]; «виртуальные рейки» по скалам/объектам без реальной рейки — MAE 8.8 см, bias +5.8 см, суточное усреднение сглаживает [23].

**Готовые инструменты для чтения рейки:**
- NRCan `snow-depth` (Python, цветные маркеры на рейке, trail-cam 3 Мп) — https://github.com/NRCANTerry/snow-depth [24], метод — Fernandes et al. 2019 [25].
- FMIPROT (FMI Image Processing Toolbox) [22].
- «Virtual snow stakes» — R-пакет edger, Strickfaden 2023 [23].
- Примеры: snow-stake cams Alta/Mammoth (обновление каждые 10 мин) [26]; NEON PhenoCam — рейки в поле зрения камер [27].

**Железо:**
- Reconyx HyperFire 2 (~$450–550 (?)): литиевые AA работают до −40 °F/°C [28]; time-lapse режим штатный.
- Browning/Bushnell с time-lapse — $100–200 (?), тоже Energizer Ultimate Lithium.
- Рейка: белая ПВХ-труба Ø 4 см, 2–3 м, чёрные метки через 2–5 см + цветные маркеры (для NRCan-тула); яркая окраска верхушки (чтобы найти после заметания).
- Передача: (а) SD-карта, читается при следующем визите; (б) Starlink по таймеру в лагере с людьми; (в) RockBLOCK 9704 + ESP32-CAM: слать раз в сутки JPEG-миниатюру ~10 КБ ≈ $5/сут — дорого, лучше слать ЧИСЛО (см. п. 2). Спутниковые фотоловушки как класс только появляются: SPYPOINT FLEX-RANGE (анонс SHOT Show 01.2026, цена/партнёр не раскрыты, поставки «позже в 2026», только Северная Америка) [29][30].

**Время подготовки:** 1–3 дня (камера + рейка + анкеровка). **Установка:** любой спасатель за 20 мин: рейка вбивается/вмораживается или крепится к скале, камера на скале/треноге в 5–15 м, объектив на север (против солнца), кадр раз в 1–3 ч днём.
**Автономность:** 8–12 AA Li — вся зима при 8–24 кадрах/сут.
**Риски:** заметание камеры/рейки (ставить рейку 3 м, камеру выше по склону), налипание снега на объектив, лавина, ветровой перенос (рейку ставить на ровной «представительной» площадке, не в кулуаре). Без спутникового канала данные — только при возврате.
**Оценка:** **4/5** для ABC/C1 (данные при визите или через Starlink лагеря); 2/5 для C2 (никто не прочтёт до весны).

**Референс-платформа:** **Cryologger AWS** (Arduino + RockBLOCK 9603, датчики T/RH/ветер/снег, наклон, батарея; Канадская Арктика 2018–2025) — https://github.com/cryologger/automatic-weather-station [37]. Полностью открытая прошивка; трекер-версия ~$700 [38], АМС в сборе ~$1 500–2 500 (?).

**Конфигурация «минимум» (рекомендую):** ESP32/Arduino (Feather M0/RP2040) + MB7354 + DS18B20/SHT31 + RockBLOCK 9603N/9704 + 20 Вт солнечная панель + аккумулятор + Pelican-кейс на мачте 2.5–3 м над снегом (датчик смотрит вниз, ≥50 см над макс. ожидаемым снегом, столб не в зоне ветровой тени).

**Питание при −20…−30 °C:**
- LiFePO4 **нельзя заряжать ниже 0 °C** (литиевое осаждение) — нужен BMS с отсечкой + самоподогрев или подогрев от панели [39][40]. Проще: **первичные литиевые** элементы (Energizer L91 AA или Li-SOCl2 D-cells) без солнца вообще — при 1 сеансе Iridium/сут (≈0.5 Вт·ч) и спящем МК связка 8×D Li-SOCl2 (~150 Вт·ч) тянет >1 года. Это подход Cryologger.
- Если нужно больше (камера, частые измерения) — LiFePO4 в утеплённом боксе + нагреватель, либо свинцовый AGM (заряжается на морозе, но теряет ёмкость).

**Стоимость узла:** датчик $170–230 + модем $280–300 + МК/панель/батарея/бокс/мачта $250–400 → **$900–1 300** + **$22–30/мес** связи.
**Точность:** ±1–3 см (ультразвук в спокойном воздухе; при снегопаде/ветре выбросы — медиана по 10 замерам).
**Время подготовки:** 1–2 недели (закупка модема — доставка из UK/US 5–10 дней, пайка/прошивка 2–3 дня, тест сутки).
**Установка:** 1 человек, 30–60 мин; вертолётом на C1/C2 при заброске; на ABC — руками.
**Автономность:** сезон+ на первичных батареях.
**Риски:** заметание выше датчика (мачта 3 м), обледенение мембраны (MB7554 самоочистка), сваливание мачты ветром (оттяжки, анкеры в скалу), лавина, кража/повреждение животными (на ABC — пастухи). Антенна Iridium должна видеть небо ≥ ±45°: ставить не под стеной.
**Оценка:** **5/5** для ABC/C1, **4/5** для C2 (если довезёт вертолёт).

## 4. Спутниковая передача с датчика — что выбрать

Ранжирование для задачи «1–4 числа в сутки, Кыргызстан, мороз»:

1. **RockBLOCK 9603N / 9704 (Iridium)** — единственный вариант «заказал → через 2 недели работает». $280–300 + $17/мес + копейки за байты [1][2][3][4]. Прошивки готовые (Cryologger, SparkFun IridiumSBD lib). Сообщения приходят на e-mail/HTTP-webhook Ground Control → парсер → таблица/Telegram-бот штаба.
2. **Iridium Edge Solar** ($413 [46]) — 10 лет на солнце, но это трекер (GPS + BLE), не универсальный вход для датчика; годится как «маяк жив/температура» — 2/5.
3. **inReach/Zoleo/Bivy** — только через человека; но inReach IPC Outbound API позволяет автоматически парсить пресет-сообщения спасателей в базу [16].
4. **Starlink (КР с 05.2026)** — для лагеря с людьми/генератором: ~$450 + $62/мес [10][12]; для автономной точки — только с таймером питания (не проверено на морозе, снеготаялка ест ток [14]). Уточнить у местного дилера, продаётся ли Mini и работает ли KG-план на 5000 м (лицензия по стране — да; ограничений по высоте нет (?)).
5. **Astrocast** — дёшево по трафику ($1.30/КБ/мес [7]), но модуль по запросу, латентность часы, Центральная Азия — уточнять; 2/5 на этот сезон.
6. **Lacuna/Sateliot** — экспериментально, 1/5 на этот сезон [8][9].
7. **Swarm** — нет [5][6].
8. **LoRa до долины**: от ABC до Сары-Таша ~35–40 км, прямой видимости нет (хребты) — нет; реально только LoRa «датчик на C1/C2 → шлюз на ABC» (3–8 км, прямая видимость по долине ледника — проверить по DEM), а с ABC уже Iridium/Starlink. Это снижает число модемов до одного.

## 6. Дрон: повторная фотограмметрия, LiDAR, дальномер

**Ограничения по высоте:** Mavic 3E/3T и Matrice 4E — потолок **6000 м над у.м.**, −10…+40 °C (M3E) [50][51]; Matrice 350 RTK — 5000 м стандартными и **7000 м** винтами 2112 [52]. На 5500 м тяга ~55–60 % от уровня моря → время полёта падает до 15–20 мин, ветер >10 м/с — не летать. Mavic 3 Enterprise снят с производства, преемник — Matrice 4E (тот же LRF) [53].

**Точность SfM-разности DEM (свежий снег vs. базовый DEM):**
- Bühler et al. 2016: RMSE **7 см** на траве/снегу, 30 см в кустах [54]; Harder et al. 2016: **16 см** [55]; Cimoli et al. 2017: 10–15 см; сводка по альпийским работам: **7–30 см** [56]; Goetz 2019 — бюджет неопределённости [57]; Eberhard 2021 — интеркомпарация платформ [58].
- Для *разности* двух дроновых DEM (а не дрон−наземка) ошибка ~√2 больше → реально **10–25 см** при GSD 3–5 см, что для ответа «намело 0.5 м или 1.5 м» достаточно.
- **Бестекстурный снег:** главная проблема — свежий ровный снег в тени/при плоском освещении даёт «дыры». Помогают: съёмка при низком солнце (тени от заструг), NIR-камера (Bühler 2017 [59]), перекрытие **80 % продольное / 70 % поперечное**, кросс-полёт, наклон камеры 10–15°, GSD ≤ 5 см (высота 100–150 м над склоном).
- **Без GCP:** RTK на M3E/M4E даёт см-точность позиции [60], но для разности DEM GCP **не нужны**: совмещать модели по стабильным скалам (Nuth & Kääb co-registration / ICP по скальным выходам, уже есть в вашем пайплайне COLMAP/DEM). Достаточно 4–6 «виртуальных GCP» на скалах, видимых в обоих сетах.
- Объём: участок 500×300 м на 120 м → ~150–250 кадров, 2 батареи; обработка — ваш существующий SfM.

**Дрон-LiDAR (Zenmuse L2):** аренда $300–350/день в США/Канаде [61][62]; в Кыргызстане проката не найдено (?), нужна Matrice 350/400 — логистически неоправданно. Плюс — работает на бестекстурном снегу; минус — цена, вес, потолок. **2/5.**

**Лазерный дальномер DJI как «снегомер»:** M3E/M4E LRF: 1800 м, **точность ±(0.2 + 0.0015·D) м** (при 300 м — ±0.65 м; случайная <0.1 м@1σ) [63]. Для абсолютного замера расстояния до склона с воздуха — слишком грубо и не воспроизводимо (позиция дрона плавает даже с RTK на см, а наклон/точка попадания — на метры). Полезен только как **дальность до репера для масштаба фото** (п. 7). **2/5 как снегомер.**

**Что даёт «бесплатно» при очередном облёте:** если летать по сохранённому маршруту (DJI Pilot 2 → тот же waypoint mission, та же высота над рельефом, то же время суток) — разность DEM зоны 5385–5485 м с точностью 10–25 см и, важнее, **карта где сдуло/намело** (лавинные конуса, надувы у скал — именно там могут быть предметы). Оценка **4/5** при наличии вертолёта/дрона всё равно.

## 7. Простейшее: фото скальных реперов с фиксированной точки

**Метод:** выбрать 5–10 характерных камней/скальных выходов вдоль зоны интереса и на ABC/C1/C2 (высота над снегом 0.5–3 м, разные экспозиции). Сейчас, пока снега нет, **измерить их высоту** (рулетка на ABC; для верхних — из вашей SfM-модели/ортофото либо LRF дрона + зум с двух ракурсов). Дальше при каждом облёте/визите — фото с того же места (координаты + азимут + фокусное в EXIF, для дрона — hover-точка в миссии). «Сколько камня осталось над снегом» → прирост с точностью **±10–20 см** (метод «virtual snow stakes», MAE 8.8 см на trail-cam [23]; с зумом DJI 56× — лучше).

**Стоимость:** $0 (+ баллончик оранжевой краски для отметки уровней на камнях на ABC — 10 см полосы, $10). **Подготовка:** 1 день (выбор реперов по вашему ортофото, замер, карточка с эталонными фото). **Риски:** снег у камня не репрезентативен (надув/выдув) — брать несколько реперов и медиану; при полном заметании репер теряется — включать высокие. **Оценка: 5/5 по цене/усилию, 3/5 по точности.**

Для ABC можно добавить: **2 рейки по 3 м с цветными маркерами** + trail-cam (п. 1) — вместе с реперами это замыкает наземную часть.

## Ранжированная рекомендация

**(а) За 1 неделю и $200–500 — ставить сейчас, при заброске этапа 3:**
1. **Реперы (п. 7)**: выбрать по ортофото 6–10 камней в зоне 5385–5485 м и у C2/C1/ABC, замерить их высоту над грунтом (SfM/LRF/рулетка), завести карточку «репер → эталонное фото → высота». Протокол для вертолёта/дрона: те же точки, тот же зум. $10.
2. **Две рейки 3 м + trail-cam с time-lapse** на ABC (и одна рейка на C1, если будет визит): Browning/Bushnell $150 + ПВХ-труба + литиевые AA. Чтение — NRCan snow-depth tool [24]. $200–300.
3. **inReach-пресеты** у спасателей: «ABC snow ХХ см / C1 snow XX см / снегопад да/нет» — приходят в почту/по API [16]. $15/мес на уже имеющемся устройстве.
4. Спросить Ак-Сай/Central Asia Travel, остаётся ли кто-то в Ачик-Таше после 30.08 [47] и есть ли у них метеостанция (не найдено публично).

**(б) За $1–3k — один-два автономных узла Iridium (п. 2):**
- Узел «ABC» (и по возможности «C1/C2» вертолётом): ESP32 + MaxBotix MB7354/MB7554 + T/RH + RockBLOCK 9603N (или 9704) + мачта 3 м + первичные литиевые батареи в утеплённом кейсе (Cryologger-подход, без солнечных панелей и без LiFePO4-проблем с зарядом на морозе). ~$1 000–1 300/узел + $22–30/мес. Заказ модема — сегодня (доставка 1–2 нед); пока едет — пайка/прошивка по Cryologger [37].
- Опционально к нему: totalizer с тензодатчиком HX711 ($60) на том же модеме → «мм воды» в тех же сообщениях.
- Если в лагере будут люди с питанием — **Starlink KG-комплект** ($450 + $62/мес [10][12]) + IP-камера на рейку: ежедневные фото и полноценная связь штаба, но только пока лагерь жив.

**(в) Что дадут дрон-повторы «бесплатно» при очередном облёте:**
- Сохранённая waypoint-миссия над зоной 5385–5485 м: 80/70 % перекрытие, GSD 3–5 см, кросс-галс, съёмка при низком солнце; совмещение по скалам → **dDEM ±10–25 см** и карта надувов/выдувов (где искать после снегопада). Потолок M3E/M4E 6000 м — хватает [50][51].
- Hover-фото каждого репера с зумом (п. 7) + LRF-дальность для масштаба.
- LiDAR (L2) не арендовать — нет проката в КР, не окупается [61][62].

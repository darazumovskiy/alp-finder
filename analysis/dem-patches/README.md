# DSM-патчи рельефа (фотограмметрия C C)

Копии `out/terrain/{transit_19,transit_21,transit_30}/dsm.tif` из репозитория
`external/kurumdy-image-lab` (коммит `7120c89`). Плотная реконструкция рельефа
по транзитным пролётам дрона, WGS84, шаг ~1 м, высоты в системе телеметрии
полёта (≈ эллипсоидальные). NaN — где реконструкции нет.

`geoproject.Dem` подхватывает все `*.tif` из этой папки автоматически и
накладывает их на GLO-30 полем поправок — механика и валидация в
`docs/dem-patches.md`. Файлы не редактировать; новые патчи от автора класть
рядом и перезапускать пересчёты по списку из того же документа.

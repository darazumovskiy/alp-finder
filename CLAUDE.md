# alp-finder — Claude Code

Поисково-аналитический проект: помощь штабу поисковой операции на пике Курумды (Кыргызстан) в отсмотре съёмок с дрона и вертолёта. Три альпиниста пропали при спуске после восхождения 2 августа 2026. Задача проекта — алгоритмическая предобработка десятков часов видео и выявление подозрительных кадров для передачи координат штабу.

**Это не учебный проект. От скорости и качества работы может зависеть жизнь людей.** Любая находка перепроверяется перед передачей штабу.

## Точка входа: три скилла

Используйте `/` для вызова скилла по имени:

- **/priyom-novykh-video** — Приём новых видео съёмки: закачка, телеметрия, сканы, ИИ-отсмотр, отчёт. Использовать, когда появились новые видео на Drive или нужно обновить покрытие.

- **/tochka-na-kartu-po-foto** — Добавление находки на карту по фото/скриншоту: атрибуция, SIFT-сверка, координаты, карточка в реестр, деплой. Использовать, когда волонтёр или оператор приносит кандидата.

- **/kuda-smotrit-dron** — Разбор ракурса дрона: где дрон, куда смотрит, что видит, какие находки в кадре. Использовать для аналитики ракурсов и проверки геометрии.

## Контекст операции

Подробности: [docs/operation-context.md](docs/operation-context.md). Ключевое:

- Район: пик Курумды (6096 м), Чон-Алайский хребет, восточнее пика Ленина.
- Критичный неосмотренный участок: между лагерями 2 и 3.
- Штаб выкладывает съёмку в Google Drive `1uD9uCzOm9e2GdKYiOO2Jp3GVvE8Cn3XX`.

## Быстрый старт

### Поднять окружение

```bash
python3 -m venv analysis/.venv
analysis/.venv/bin/pip install -r analysis/requirements.txt

# модель рельефа Copernicus GLO-30
mkdir -p data/dem
curl -o data/dem/N39E073.tif \
  https://copernicus-dem-30m.s3.amazonaws.com/Copernicus_DSM_COG_10_N39_00_E073_00_DEM/Copernicus_DSM_COG_10_N39_00_E073_00_DEM.tif

# детальный рельеф NASA HMA 8 м для 3D-вьюера (нужен токен Earthdata,
# рецепт скачивания и сборки — шапка analysis/build_hma_dem.py)
```

### Локальный просмотр

```bash
# видео с Drive (если нужны)
bash scripts/download_drive.sh

# просмотрщик на http://localhost:8077
python3 -m http.server 8077 -d .
# открыть: http://localhost:8077/analysis/viewer/index.html (кандидаты)
#          http://localhost:8077/analysis/viewer/map.html (карта)
```

## Правила работы

- Сначала инвентаризация и документирование, потом обработка.
- Все выводы фиксируются в `docs/` — контекст проекта живёт в файлах, не в чате.
- Кандидаты-находки: файл, таймкод, координаты, скриншот, степень уверенности.
- **Любая находка перепроверяется перед передачей штабу**: ложные срабатывания
  тратят ресурс спасателей, пропущенные кадры — хуже.
